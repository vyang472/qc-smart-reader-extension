# Support

QC Smart Reader is an early public, community-supported project. The fastest path to an answer is to choose the right channel and include a minimal, redacted reproduction.

## Start here

1. Follow the release installation steps in [README.md](README.md) or [README.zh-CN.md](README.zh-CN.md).
2. Check [从零到能用](上手指南.md), especially its error table.
3. Search [Discussions](https://github.com/vyang472/qc-smart-reader-extension/discussions) and [Issues](https://github.com/vyang472/qc-smart-reader-extension/issues).

## Where to ask

- **Setup, usage, and workflow questions:** [GitHub Discussions](https://github.com/vyang472/qc-smart-reader-extension/discussions)
- **A reproducible defect:** [open a bug report](https://github.com/vyang472/qc-smart-reader-extension/issues/new?template=bug_report.yml)
- **A product idea tied to a user problem:** [open a feature request](https://github.com/vyang472/qc-smart-reader-extension/issues/new?template=feature_request.yml)
- **A vulnerability or possible private-data exposure:** follow [SECURITY.md](SECURITY.md); never post it publicly

## Include in a support request

- QC Smart Reader version;
- macOS, Chrome, Python, Node, and Codex CLI versions when relevant;
- whether installation came from release ZIPs or a source checkout;
- the exact action taken and expected versus actual result;
- the complete error text with paths and private content redacted;
- whether `bash scripts/test_all.sh` passes in a source checkout;
- a synthetic public URL or minimal fixture when extraction is involved.

Before posting, remove Pairing Tokens, API keys, authorization headers, private source text, Vault contents, personal file paths, and browser profile data. Do not upload the SQLite database.

## Response expectations

Support is best-effort; response and fix times are not guaranteed. Clear reproductions and small public fixtures are much easier for maintainers and contributors to act on. Provider billing, account access, private captions, paywalls, and general Chrome or macOS administration remain the responsibility of the relevant provider.
