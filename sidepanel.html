本地服务

采集内容保存在本机 Vault。零配置本地模板不调用外部模型；只有你明确同意后，才会把内容发送给已配置的模型。

首次使用 · 3 步完成

  1. 正式版双击 Companion 包里的 install.command；源码开发时才用 start.command。
  2. 粘贴安装器复制的 Pairing Token，点击“测试本地服务”。
  3. 配对成功后直接运行 Quick Start；默认本地模板零配置，只有切换外部模型时才需要隐私同意。

模型设置

数据默认保存在本机 Vault，不用于广告或开发者分析。查看完整隐私说明。

模型 API Key 保存到 companion service 的本地配置文件，不再写入 Chrome storage。OpenAI-compatible 可填 OpenAI、OpenRouter、DeepSeek、智谱兼容网关等支持 /chat/completions 的地址。

选 Codex CLI 时不需要 Base URL 和 API Key：companion service 直接调用本机 codex exec，用你已登录的 ChatGPT 订阅。命令留空会从服务进程的 PATH 自动查找；模型名留空即用 Codex 默认模型。单次调用比 API 慢，适合逐篇精读，不适合上百条批量。
